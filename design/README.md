# 界面与交互设计规范

本文规定 JustMarkdown 当前界面的视觉层级、布局、组件行为与动效，面向设计和实现维护者。模块关系、数据流及文件访问边界见[架构设计](../docs/native-architecture.md)。

## 设计原则

- 正文是阅读界面的主体。操作按需呈现，收起的面板释放正文空间。
- 采用系统控件、语义颜色、原生材质和系统选择菜单，保持触控、指针与键盘操作的一致性。
- 同一内容共用渲染能力，同一操作共用组件；布局变化不改变操作含义。
- 文案说明当前对象、状态或后果。保留必要标签与无障碍名称，避免欢迎语、预设提问和重复提示。

## 视觉基础

| 要素 | 规范 |
| --- | --- |
| 品牌 | 首页标志与系统 App 图标由同一矢量母版和配色生成。首页保留图形原色；系统图标的外形由系统处理。制作方法见[品牌资源](brand/README.md)。 |
| 字体 | 原生界面使用系统语义文本样式。首页 slogan 使用离线打包的 Newsreader Regular，按 Title 2 缩放；整句保持同一字体、字重和颜色。源码和代码使用等宽字体。 |
| 颜色 | 原生容器使用系统背景、标签、分隔线与强调色；Web 正文接收原生解析后的语义颜色。选中、标记、语法和修改差异使用各自的语义色。 |
| 材质 | 阅读页悬浮控件使用圆形、可交互的系统 Liquid Glass，按压、指针和聚焦反馈保持同一外形。 |
| 对齐 | 同一组控件共享中心线、尺寸和有效触控范围。对话正文与输入区共享左右边界；引用标记、首行和移除动作对齐。 |
| 可访问性 | 图标操作保留可访问名称。文字适应系统大字号，内容允许换行和滚动；反馈同时通过文字或控件状态表达。 |

尺寸、间距、颜色和动效参数由 [tokens.json](tokens.json) 维护。原生语义样式与 Web 的平台适配分别由原生视图和 `WebSource/native.css` 实现；系统材质不以 CSS 透明度或模糊半径模拟。

## 布局与适配

布局响应可用窗口空间。原生操作区依据系统横向 size class 适配；目录和 AI 面板分别依据正文可用宽度适配，支持旋转与分屏。

| 区域 | 紧凑布局 | 空间充足时 |
| --- | --- | --- |
| 首页 | 品牌与操作纵向居中；空间不足时整组可滚动 | 保持紧凑的品牌组与操作组，周围留白弹性分配 |
| 阅读操作 | 右下角一个展开按钮，向左展开操作 | 直接显示共享操作 |
| 正文目录 | 展开时覆盖正文 | 展开时与正文并排 |
| AI 对话 | 底部模态面板 | 右侧面板与正文并排 |
| 最近打开 | 可调整高度的系统 sheet | 锚定入口的 popover |

阅读界面不设顶栏。预览和源码至少填满可用视口，长文随内容增长，旋转和分屏后按新窗口尺寸布局。目录开关位于左上方，关闭文档位于右上方，两者对齐；底部操作避让已展开的 AI 面板。目录收起后占用宽度为零，仅开关保留有效触控范围。

阅读视口与背景延伸至屏幕底部，不以独立空白条保留底部安全区。悬浮操作与 AI 输入仍避让 Home 指示条；正文和源码的末尾留有可滚动的避让空间。

## 首页与最近文档

首页依次呈现标志、`just markdown, pure reading.`、打开文档主按钮和最近打开次级文字按钮。标志与 slogan 组成品牌组，品牌组和操作组之间使用更大的间距。主按钮保持主要操作层级，最近打开入口使用次级颜色与完整触控范围。

slogan 在宽度足够时显示一行；窄布局先在逗号后的短语边界换行，大字号下允许继续自然换行。各行保持相同样式，不通过缩小文字强行容纳。

中文最近打开入口为“最近打开...”，使用三个 ASCII 点号。列表项展示文件名和父文件夹，按最近成功打开的顺序保留十个不同文档；重开已有文档将该项移到首位。空列表显示空状态，打开失败保留列表并提示错误。紧凑布局的关闭动作与标题同排；popover 可点击外部关闭。

隐私政策仅在首页底部安全区的右侧提供文字入口，使用系统 Caption 与次级颜色，触控范围不小于共享标准。入口与中央品牌、操作组分开，不覆盖滚动内容。点击打开原生模态窗口，使用系统导航栏和关闭动作；正文随 App 语言选择中英文，使用原生文本、列表、表格和滚动容器，支持离线阅读、大字号和深色外观。滚动视口延伸至弹窗底部，内容通过系统安全区避让，保持圆角边界连续。

## 阅读与源码

预览呈现只读文档；源码显示并编辑 Markdown 原文。两种视图共享 AI、视图切换和更多操作，更多仅包含模型设置。紧凑布局选择 AI 或切换视图后收起操作组，隐藏操作退出触控和焦点范围；源码额外提供撤销、重做，执行历史操作后保留操作组，不能执行的动作显示为禁用。

切换视图跟随当前内容：切换前视口顶部的段落或代码行，在目标视图中保持大致相同高度。目录跳转定位正文，源码与预览显示同一份文档内容。关闭文档先保存，成功后返回首页。

### 目录导航

| 操作 | 行为 |
| --- | --- |
| 滚动正文 | 更新当前章节，让对应目录项在目录面板中大致居中；首尾处按可滚动范围收敛 |
| 快速滚动或反向滚动 | 从目录当前的位置与速度连续跟随最新章节，不排队执行过时目标 |
| 手动浏览目录 | 暂停自动跟随；重新操作正文或重新打开目录时恢复 |
| 点击目录项 | 跳转正文并使用当前项反馈；触控反馈与行样式保持一致 |
| 收起分支 | 以可见祖先代表当前后代，不强制展开用户收起的分支 |

展开与收起复用同一个圆形目录开关，不附加可见文字标题，保留可访问名称。没有可生成的目录项时隐藏开关和面板，不占正文宽度；编辑后重新生成目录时同步更新可用性。目录行共享前导触控列和单层反馈，层级仅改变文字缩进；分支展开动作与标题跳转分别响应。自动跟随只滚动目录面板。

## AI 对话

全局 AI 入口使用当前文档，不能沿用已经放弃的选段。预览和源码的系统选择菜单都提供一个“AI”动作，使用实际选中内容进入同一对话。界面支持多轮交流，输入区保留可访问名称，不显示输入占位语或预设问题入口。

预览中的 AI 辅助阅读；用户要求修改时，引导其切换到源码。源码中的 AI 也可解释和讨论，只有明确的修改要求才执行文档编辑。实际修改以变化卡片呈现，区分已修改、已撤销与保存失败；卡片中的撤销遵循当前历史顺序，不越过后续编辑。技术权限与执行过程见[架构设计](../docs/native-architecture.md#ai-上下文与编辑执行)。

首次向某个服务发送前，用系统确认弹窗说明全文、提问和本次对话将发送到该服务地址，提供“取消”和“允许”。确认前不提交对话轮次；取消保留草稿与引用，不发送请求。允许后在设备上记住该服务，重启不重复询问；更换服务地址重新确认，切换模型、接口类型或更新 API Key 不重复询问。失败轮次改向另一个服务重试时同样需要确认，取消不改变已有回复。打开 AI 面板与查询模型列表不触发文档发送授权。

### 引用与输入

当前引用完整展示在输入区，长内容在限定高度内滚动。引用标记与移除按钮仅占据开头附近的空间，后续文字回收整行宽度；表格、代码等宽块排列在控制区下方。滚动条为细圆角滑块，无可见轨道和箭头，滚动或指针悬停时出现，闲置后淡出。

| 引用范围 | 呈现规则 |
| --- | --- |
| 全文 | 展示文件名，并可展开查看内容 |
| 普通选段或单个表格单元格内的选段 | 保留选中内容的富文本，不附加源码行号或一行摘要 |
| 跨单元格选段 | 仅保留选中内容及相对网格位置；边界可保留空单元格，跨行范围按选区裁切，不补入未选中的标题或文字 |
| 完整表格 | 保留表题、合并单元格、对齐与行内格式 |
| 表格前后的选段 | 保持在表格之外，按原顺序排列 |

待发送引用随当前草稿变化，已发送引用保持不可变。用户提问、引用和 AI 回答共用富文本渲染能力，脚注、上标和下标保留各自语义。

软件键盘的回车插入换行，发送按钮提交。实体键盘 Enter 发送、Shift＋Enter 换行；输入法确认与重复按键不会误提交。生成期间可继续编辑下一条草稿，回车保留草稿且不打断生成；收起面板保留会话和生成，停止按钮取消当前生成。

### 请求反馈

| 状态 | 界面与操作 |
| --- | --- |
| 未配置 | 简洁提示提供取消和设置；成功配置并关闭设置后恢复原入口及引用，等待用户发送 |
| 生成中 | 增量呈现回答，提供停止；保持已完成内容和用户手动滚动位置稳定 |
| 完成或停止 | 保留已经显示的内容及已发生的文档修改 |
| 失败 | 在该轮回答内展示简洁原因和手动重试入口，保留草稿、引用与部分回答 |
| 重试 | 仅最新失败轮次可原位重试；收到替代内容后再替换旧回答，已有部分回答时明确表示重新生成 |
| 限流等待 | 等待结束后恢复重试按钮，由用户决定是否重试 |

## 模型设置与系统提示

模型设置以前置原生模态呈现，背景在关闭过渡结束前保持不可交互。连接项包括接口类型、Base URL、API Key 和模型；默认使用 Responses，可明确选择 Chat Completions。

设置页预取模型列表，模型选择页支持本地搜索，并将当前模型独立展示。“自定义”在加载、失败和空结果时均可使用，选择后返回设置并聚焦模型 ID 输入。搜索忽略大小写、空白和 ASCII 连字符，保留版本点号；选择结果始终使用供应商原始 ID。当前选择页的列表快照保持稳定，后台刷新不会在挑选过程中重排项目。

打开文档、加载本地图片授权和保存失败使用系统提示或选择器。图片授权请求提供建议目录，用户在系统选择器中完成授权后重载资源。保存失败保留当前内容；关闭时提供重试、明确放弃修改并关闭、取消三种选择。

## 文档渲染范围

基础语法由固定版本的 markdown-it 解析，扩展能力按下表维护。正文、引用和对话共用解析与清理流程，针对显示区域采用对应排版。

| 类别 | 支持范围 |
| --- | --- |
| 基础 Markdown | 标题、段落、强调、删除线、引用、列表、分隔线、链接、图片和自动链接识别 |
| 代码 | 行内代码、围栏及缩进代码块；已识别语言语法高亮，其余保留等宽代码显示 |
| 表格与注释 | Markdown 表格、任务列表、脚注与对应回链 |
| 图片与跳转 | 授权范围内的相对图片和本地 Markdown 链接，包括父目录引用；支持网络图片和系统外部链接跳转 |
| 数学公式 | KaTeX 支持的 LaTeX 子集，包含行内及块级公式，依赖随 App 离线打包 |
| 图表 | Mermaid 代码块，使用随 App 打包的引擎并启用严格安全模式 |
| HTML | 经清理的 HTML，包括表格及上、下标等语义元素；脚本、交互表单、内嵌页面和自定义样式被移除 |

宽表格和代码块在自身区域滚动，正文保持可读宽度；图片适应正文宽度。图表或公式解析失败时保留可读的原始内容。标题、目录和跳转目标均来自文档本身；空标题及其目录项按原文保留，不过滤、补名或修正文档内容。

## 动效

| 场景 | 行为 | 参数键 |
| --- | --- | --- |
| 首页进入 | 标志、slogan 和操作从上到下依次向下滑入并渐显；同一有序集合决定布局与顺序 | `homeEntrance` |
| 视图切换 | 淡出当前视图，完成目标排版与内容定位后淡入 | `modeOut`、`modeIn` |
| 面板与操作展开 | 保持触发控件位置，转场可被快速反向操作打断并连续衔接 | `layout`、`tools`、`agentPanel` |
| 引用、回答与修改反馈 | 内容变化局部过渡，保持正文、输入区和用户滚动位置稳定 | `reference`、`message`、`proposal`、`editFeedback` |

自定义动效使用共享参数，系统控件遵循原生转场。开启 Reduce Motion 时直接呈现目标状态，取消位移与装饰动画；必要的内容定位仍须完成。离开首页取消入场任务，返回时重新播放，新增中央元素通过同一集合参与排序，底部政策入口保持独立。

## 维护入口

| 修改内容 | 维护位置 |
| --- | --- |
| 界面行为和视觉规则 | 本文 |
| 组件归属、复用边界和核心不变量 | [components.json](components.json) |
| 共享数值、颜色及动效参数 | [tokens.json](tokens.json) |
| 操作与图标的对应关系 | [icons.json](icons.json) |
| 品牌图形、配色与导出 | [品牌资源](brand/README.md) |
| 界面文案与翻译 | `JustMarkdown/Localizable.xcstrings`、`InfoPlist.xcstrings` |

组件与图标登记是人工维护的索引，不会自动生成界面。修改组件时同步核对登记和实现；资源生成与验证方法统一见[贡献指南](../CONTRIBUTING.md)。
