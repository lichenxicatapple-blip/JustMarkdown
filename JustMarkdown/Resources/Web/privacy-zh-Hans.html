1. 适用范围

本政策说明个人开发者 CHENXI LI（下称“我们”）发布的 JustMarkdown 如何处理信息。 第三方自行修改或分发的版本，应以相应发布者提供的政策为准。

JustMarkdown 是本地 Markdown 阅读与编辑工具，不要求注册账号，不包含广告、分析 SDK 或跨 App 跟踪功能，也不提供由开发者运营的文档存储、同步或 AI 中转服务器。

2. 在设备上处理的信息

信息 用途与保存方式
你选择的文档及授权范围内的图片等资源 用于阅读、渲染和编辑。文档在原位置保存；应用按系统授予的范围访问文件，不会自动将这些文件上传给开发者。
最近打开记录 在设备上保存最近 10 份不同文档的名称、位置、文件与资源目录的系统授权书签，用于重新打开。记录不包含正文副本；书签不能绕过系统权限。
模型设置 服务地址、模型名称和接口偏好保存在应用的本地设置中，用于建立你指定的连接。
AI 发送授权 在设备上保存已允许服务地址的摘要标识。对同一服务不重复询问；切换模型或更新密钥不改变该授权。
API Key 保存在本机钥匙串，采用设备解锁时可访问、仅限本设备的保护等级。密钥由原生网络层用于认证，不交给文档渲染网页，也不作为 AI 对话正文发送。

AI 对话和编辑上下文在当前文档会话中处理，不另行保存为应用的持久化对话历史。 关闭或切换文档会结束该会话；收起 AI 面板本身不会结束会话。

3. 可选 AI 服务及模型列表查询

AI 服务由你通过服务地址、模型和 API Key 自行配置。请求直接发送至你配置的服务， 不经过开发者运营的服务器。

首次向一个服务发送文档或对话前，应用会说明发送范围和接收地址，并请求你的明确许可。 取消时不发送，问题和引用保留在输入区。允许后对该服务不再询问；更换服务地址时重新请求许可。

  • 在模型设置中输入或更改有效连接信息时，应用可能自动查询模型列表；尚未点击“完成” 也可能发起查询。查询使用你填写的 API Key 认证，不包含文档正文。
  • 发送 AI 消息会将当前文档全文、所选片段、你的问题和本次会话历史发送至所配服务。 请求还可能包含文档文件名、内容版本及阅读／源码模式。仅选中一段文字不代表只发送该片段。
  • 源码编辑任务可能包含后续模型请求，以及当前文档编辑工具的参数、结果和修改内容。
  • 应用不额外加入文件的系统绝对路径，也不单独上传本地图片文件；文档正文原有的路径、链接 和其他信息仍会作为正文的一部分发送。

我们不将你的文档或对话收集到开发者的服务中用于广告、画像或模型训练。 你选择的服务提供者可能处理请求内容、认证信息、IP 地址及连接日志，其保留期限、训练用途、 处理地点和删除方式由该提供者及你与其约定的条款决定。我们无法代表任意自定义服务承诺零留存。 使用第三方服务前，请了解其隐私政策及服务条款。

4. 网络图片、链接与系统服务

文档、引用内容或 AI 回复中的网络图片可能在显示时自动向图片地址发出请求。 图片服务可能获知 IP 地址、请求地址、时间和标准网络请求信息；请求地址本身也可能包含参数。 外部链接通过系统交给相应应用或网站打开，后续处理适用其自身政策。

Apple 或你使用的文件提供程序、备份服务可能依据其政策处理下载、诊断或备份资料。 你选用的模型、图片或邮件服务也可能在其他国家或地区处理信息。 本地阅读不需要配置 AI；本地内容中没有网络资源时，渲染组件和字体可离线工作。

5. 联系我们时的信息

你向联系邮箱发送邮件时，我们会收到你的邮箱地址及主动提供的信息，仅用于处理来信、 回复、必要的后续沟通及履行适用法律义务。邮件会经由电子邮件服务提供者处理， 按上述目的所需保留。请勿发送 API Key 或无关的私人文档。

6. 保留、删除与用户控制

  • 原文档和图片由你在其保存位置管理、移动或删除。删除应用不会自动删除保存在其他位置的原文档。
  • 最近打开记录最多保留 10 项，较旧记录随新记录加入而移除。删除应用可清除其本地设置、发送授权和最近记录； 系统备份、文件提供程序及钥匙串可能按系统规则独立保留信息。
  • 你可以在模型设置中清空 API Key 并保存，以清除应用保存的密钥值，也可在服务提供者处撤销密钥。 不应仅依赖卸载应用来清除钥匙串中的密钥。
  • 你可以不使用 AI，或停止正在进行的生成。停止操作不能撤回服务已经收到的内容。 对第三方已收到数据的访问或删除请求，需要向该服务提供者提出。
  • 你可通过上述邮箱，就我们实际持有的信息提出访问、更正或删除请求。我们将根据适用法律和 实际可控范围处理；我们无法远程访问或删除你设备上的文档。

7. 信息保护

应用利用系统文件授权、钥匙串及网页内容隔离等措施限制信息访问。 模型连接允许你配置本地或其他 HTTP 服务；HTTP 不提供传输加密，互联网服务建议使用 HTTPS。 任何安全措施均不能保证绝对安全，选择服务地址和分享文档时请考虑内容的敏感性。

8. 未成年人

本应用不要求提供年龄或建立儿童档案。未成年人使用第三方 AI 服务时，应遵守该服务的年龄要求， 并在适用法律要求时取得监护人同意。
